## 🌱 Spring Boot & Microservices (Advanced)

- [ ] How do you design a Spring Boot–based microservice architecture for a large-scale application?
- [ ] What are best practices for managing configuration across environments in Spring Boot?
- [ ] How do you handle distributed transactions in microservices?
- [ ] How would you secure microservices using OAuth2 / JWT / Spring Security?
- [ ] What's your approach to building resilient microservices? (circuit breaker, retries, timeouts)
- [ ] How do you manage service discovery and communication? (Eureka, Consul, API Gateway)
- [ ] Compare synchronous vs. asynchronous communication — when do you reach for Kafka, RabbitMQ, REST, or gRPC?
- [ ] How do you monitor and trace microservices? Which tools do you recommend? (Prometheus, Grafana, Zipkin, Micrometer Tracing / Sleuth, ELK)

## 🏛️ Architecture & Design Patterns

- [ ] How do you approach designing a new system from scratch?
- [ ] What's the difference between monolithic, microservices, and modular monolith architectures?
- [ ] Explain hexagonal (ports and adapters) or clean architecture — have you used them?
- [ ] What is Domain-Driven Design (DDD)? How do you apply it in real-world applications?
- [ ] How do you design for scalability and high availability?
- [ ] Explain your approach to API design — versioning, idempotency, pagination, error handling.
- [ ] Which design patterns do you apply most often in enterprise apps? (Builder, Factory, Strategy, etc.)
