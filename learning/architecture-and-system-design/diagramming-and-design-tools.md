Different types of diagrams
Mind map


Context diagram - C4 level 1 - This is a very high level digram that shows all entities like user, entities(functional ones), third party system
Component diagrams - C4 level 2 - Shows internal components within an entity like a service, multiple services, Database, PUBSUB topic, API gateway, broker queue
Deployment Diagram - Shows the component in terms of deployment - Server, VM, clusters, Load balancers, firewalls etc.
Sequence Diagram - Shows the sequence of a flow starting from say a user, to a service, ext. service and so on.

Data flow diagram - Shows the flow of data within the system
Source/Sink - Represented as rectangles - User, system, external entities
Processes - Circles - Data transformation like Order processing, validation etc.
Data Store - Open ended rectangles 
Data flow - Arrow
